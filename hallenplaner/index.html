🏟️ Hallenplaner
Gerät anklicken = wählen, ziehen = verschieben (R = drehen, Entf = löschen, Geräte links hineinziehen) · leere Fläche ziehen = Ansicht drehen · «✋ Verschieben» = Ansicht mit Ziehen verschieben · Rad = zoomen · Rechtsklick = Ansicht verschieben

📝 Aufbau

📦 Materialliste

    💡 Bedienung

    • Gerät links anklicken oder in die Halle ziehen.
    • Ziehen = verschieben, runder Griff = drehen.
    • Gerät auf ein anderes ziehen (z. B. Matte auf Kasten) = aufeinander. Bank an die Sprossenwand ziehen = einhängen.
    • Mehrere wählen, dann 🔗 Gruppieren (Ctrl/⌘+G): bewegt sich gemeinsam.
    • Linien und Pfeile: Doppelklick setzt einen Biegepunkt – so entstehen beliebige Bögen.
    • Shift + Klick oder Rahmen ziehen = mehrere wählen.
    • R / Shift+R drehen · Entf löschen · Ctrl/⌘+D kopieren · Pfeiltasten schieben.
    • Leertaste + Ziehen oder mittlere Maustaste = Halle verschieben, Mausrad = zoomen.
